# The F4 Prestige Archive

A public, player-facing showcase for seven senior-year prestige class concepts from the F4 Strixhaven campaign.

**Live site:** https://aintfunny18-tech.github.io/f4-prestige-archive/

## Local development

Requires Node.js 22 or newer.

```sh
npm install
npm run dev
```

Run `npm run build` before publishing. A push to `main` deploys the validated build through GitHub Actions.

## Content boundaries

- Player-facing class language lives in `public/prestige-classes.md`.
- Portraits and sharing artwork live in `public/`.
- The private DM playtest watchpoints are intentionally excluded from this repository.
